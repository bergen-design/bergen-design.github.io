Project Overview

Category: Web Design · UX Copywriting

Software: Figma, Adobe CC, Showit

Services: Web Design, UI/UX Design, Copywriting

Designing a scalable author platform built for influence, clarity, and conversion.
Ryan Collins is a speaker, author, podcaster, and leader whose digital presence needed to reflect the breadth of his work while remaining clear, engaging, and easy to navigate. The project involved creating a reusable website system that could scale across multiple personal brands while still feeling unique, modern, and professional.

The Challenge

This project required balancing multiple brand personas inside one cohesive experience.
The goal was to create a clean, conversion-focused platform that positioned Ryan as an author, communicator, and thought leader — while building a reusable framework for future speaker/author websites.

  • Balancing Multiple Personas: The website needed to clearly communicate Ryan’s work as a speaker, author, podcaster, and ministry leader without overwhelming the user experience.
  • Limited Existing Branding: The project began with minimal photography, no established visual identity, and very few existing marketing assets to build from.
  • Need for Reusable Components: As this was created under a white label agreement, the client requested a scalable design system that could later be adapted for multiple authors and speakers.
  • Improving User Flow & Engagement: The site needed clear calls-to-action and intuitive navigation that guided users toward books, podcasts, speaking opportunities, and newsletter engagement.

My Solution — Building a Modular Author Platform

Rather than designing a one-off website, I created a reusable design system optimized for speakers, authors, and content creators.

  • Designed a Clear UI/UX Structure: I created a homepage layout that immediately communicated who Ryan is, what he offers, and how users can engage with his content.
  • Built a Reusable Design System: I developed modular layouts and reusable components that created consistency while allowing flexibility for future speaker and author websites.
  • Focused on Conversion & Engagement: Strategic calls-to-action were implemented throughout the site to create multiple low-friction pathways for user interaction.
  • Developed a Modern Visual Experience: Clean typography, balanced spacing, and responsive layouts helped create a professional website experience that feels approachable and easy to navigate.

The Final Result

The final implementation included several strategic elements:

  • A Clear & Professional Digital Presence: The final website successfully positioned Ryan Collins as a modern speaker, author, and trusted communicator.
  • Improved User Experience: The updated UI/UX structure created better navigation, stronger content hierarchy, and more intuitive engagement pathways.
  • A Scalable Website System: The reusable framework established during the project now provides flexibility for future growth and additional author platforms.
  • Stronger Visual Branding: Custom promotional assets and refined visual direction helped create a more cohesive and elevated digital identity.

What This Project Demonstrates About My Work

  • Scalable UI/UX Design: This project demonstrates my ability to create flexible website systems that can scale across multiple brands and content structures.
  • Brand Building from Limited Assets: The project highlights my ability to develop cohesive visual identities even when starting with minimal source material.
  • Strategic User Experience Thinking The final experience balances aesthetics, usability, and conversion-focused design to improve overall user engagement.
